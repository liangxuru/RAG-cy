关键配置与参数

检索参数 (QuestionsProcessor)

{ "top_n_retrieval": 10, # 检索返回数量 "llm_reranking": true, # 是否启用LLM重排 "llm_reranking_sample_size": 5, # 重排候选数 "parent_document_retrieval": false, # 父文档检索 "parallel_requests": 10, # 并发请求数 "api_provider": "dashscope", # dashscope | openai "answering_model": "qwen-turbo-latest" }

注意：Qwen-Turbo API限流为每分钟500次调用（QPM），每分钟Token消耗不超过500,000
